# Слой `features`

Пользовательские действия и интерактивные сценарии.

Реализовано:

- `add-card` — добавление карточки (название, ссылка на изображение, выбор коллекций) в форме внутри попапа.
- `create-collection` — создание коллекции (название) в форме внутри попапа.

Планируется:

- `filter-cards`, `sort-cards`, `search-cards` — управление списком карточек.
- `delete-card`, `delete-collection` — удаление.

Правила: фича может импортировать `entities` и `shared`, но не `widgets` и не соседние фичи напрямую.
