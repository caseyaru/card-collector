# Слой `widgets`

Составные блоки интерфейса, собранные из `features`, `entities` и `shared`.

- `app-header` — шапка с навигацией (используется в корневом layout).
- `app-footer` — подвал (используется в корневом layout).

Правила: виджеты не импортируют друг друга напрямую — composition происходит в `app`.
